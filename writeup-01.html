题目描述

题目提示：弱密码 top1000？z?????，目标是找出正确密码拿到 flag。

考点

  • Burp Suite 抓包与 Intruder 字典爆破
  • 前端源码 / JS 审计
  • 爆破结果的特殊筛选：所有返回包长度几乎一致，不能直接靠长度判断

思路

启动场景后，先抓包、查看页面源码。发现真正的校验不在登录表单，而是 success.php?code=xxx。提示告诉我们重点：z 开头的弱口令，从 top1000 弱密码字典里筛选 z 开头的口令进行爆破。

这题的坑：大部分响应包长度相同，常规“按长度区分”失效，需要仔细对比响应内容或者哈希，找到那个与众不同的包。

最终正确密码：zxc123，直接使用这个密码即可通过验证，拿到 flag。

解题步骤

  1. 打开靶场，F12 查看源码，留意 JS 里泄露的 success.php?code= 逻辑；
  2. 准备弱密码字典，筛选以 z 开头的口令；
  3. Burp 抓包，使用 Intruder 对 code 参数进行字典爆破；
  4. 对比返回包，找到特殊的那一条；
  5. 验证：密码 zxc123，成功获取 flag。

小结

这道题考察 Burp 爆破和细心读提示。不要死磕登录框，多看看页面源码；遇到“返回长度全部一样”的爆破题，就要想到：不能只看长度，要比对返回内容。提示是最好的线索，“z?????”直接锁定了密码的特征，大大缩小爆破范围。
